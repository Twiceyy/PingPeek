# Contributing

PingPeek is meant to stay small, so please open an issue before a pull request.

You need Windows 10 or 11 and [Zig](https://ziglang.org) 0.17 (`winget install zig.zig`). `build.cmd`
builds, `test.cmd` runs the tests (set `PINGPEEK_LIVE=1` during a match to also ping the live server).
CI must pass.
